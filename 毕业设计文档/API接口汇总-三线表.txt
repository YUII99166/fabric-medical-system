医疗信息管理系统API接口汇总

一、用户管理API接口

接口名称	请求方法	请求路径	功能描述
用户注册	POST	/register	用户注册
用户登录	POST	/login	用户登录
查询用户列表	GET	/account/list	查询用户列表
创建用户	POST	/account/create	创建用户
更新用户	PUT	/account/update	更新用户信息
删除用户	DELETE	/account/delete	删除用户

二、病历管理API接口

接口名称	请求方法	请求路径	功能描述
创建病历	POST	/prescription/create	医生创建患者病历
查询病历列表	GET	/prescription/list	查询病历列表
查询病历详情	GET	/prescription/detail	查询病历详细信息
搜索患者病历	POST	/prescription/search	搜索患者病历信息

三、授权请求管理API接口

接口名称	请求方法	请求路径	功能描述
申请授权	POST	/access/request	医生申请访问患者病历的授权
审批授权	POST	/access/approve	患者审批医生的授权请求
查询授权请求	POST	/access/requests	查询授权请求列表（医生或患者）

四、补充记录管理API接口

接口名称	请求方法	请求路径	功能描述
添加补充记录	POST	/supplement/add	医生为病历添加补充诊疗记录
查询补充记录	POST	/supplement/list	查询指定病历的补充记录列表
查询完整病历	POST	/supplement/history	查询病历及其所有补充记录

五、药品订单管理API接口

接口名称	请求方法	请求路径	功能描述
创建药品订单	POST	/drug/create	患者创建药品订单
查询药品订单列表	POST	/drug/list	查询药品订单列表

六、保险理赔管理API接口

接口名称	请求方法	请求路径	功能描述
创建理赔申请	POST	/insurance/create	患者创建保险理赔申请
查询理赔列表	POST	/insurance/list	查询保险理赔申请列表
更新理赔状态	POST	/insurance/update	更新保险理赔申请状态
删除理赔申请	POST	/insurance/delete	删除保险理赔申请

七、病历访问日志API接口

接口名称	请求方法	请求路径	功能描述
记录病历访问	POST	/access-trace/record	记录病历访问日志到区块链
查询访问日志	GET	/access-trace/logs	患者查询自己病历的访问日志
查询访问统计	GET	/access-trace/statistics	查询病历访问统计数据

八、系统统计API接口

接口名称	请求方法	请求路径	功能描述
查询系统统计	GET	/statistics/overview	查询系统整体统计数据
查询最近活动	GET	/statistics/activities	查询系统最近活动记录

九、联盟活动监控API接口

接口名称	请求方法	请求路径	功能描述
查询联盟活动	GET	/activity/list	查询联盟组织活动列表
查询活动统计	GET	/activity/statistics	查询联盟活动统计数据
