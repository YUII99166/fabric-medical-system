# 系统支撑表设计

## 表 7.1 组织机构表（organizations）结构设计

| 字段名 | 描述 | 字段类型 | 是否为空 | 主键/外键 |
|--------|------|----------|----------|-----------|
| id | 自增ID | INT | 否 | 主键 |
| org_id | 组织ID（MSPID） | VARCHAR(100) | 否 | - |
| org_name | 组织名称 | VARCHAR(200) | 否 | - |
| org_type | 组织类型（医院/药店/保险机构/监管中心） | VARCHAR(50) | 否 | - |
| domain | 域名 | VARCHAR(100) | 是 | - |
| address | 组织地址 | VARCHAR(500) | 是 | - |
| contact_person | 联系人姓名 | VARCHAR(100) | 是 | - |
| contact_phone | 联系电话 | VARCHAR(20) | 是 | - |
| contact_email | 联系邮箱 | VARCHAR(100) | 是 | - |
| description | 组织描述 | TEXT | 是 | - |
| status | 状态（1-正常，0-禁用） | TINYINT | 否 | - |
| created_at | 创建时间 | TIMESTAMP | 否 | - |
| updated_at | 更新时间 | TIMESTAMP | 否 | - |

**索引设计：**
- PRIMARY KEY (id)
- UNIQUE KEY (org_id)
- INDEX idx_organizations_type (org_type)
- INDEX idx_organizations_status (status)

## 表 7.2 审计日志表（audit_logs）结构设计

| 字段名 | 描述 | 字段类型 | 是否为空 | 主键/外键 |
|--------|------|----------|----------|-----------|
| id | 自增ID | BIGINT | 否 | 主键 |
| user_id | 操作用户ID | VARCHAR(100) | 否 | 外键 |
| username | 操作用户名 | VARCHAR(255) | 否 | - |
| user_role | 用户角色 | VARCHAR(50) | 否 | - |
| action | 操作动作 | VARCHAR(100) | 否 | - |
| resource_type | 资源类型 | VARCHAR(50) | 否 | - |
| resource_id | 资源ID | VARCHAR(100) | 是 | - |
| description | 操作描述 | TEXT | 是 | - |
| ip_address | IP地址 | VARCHAR(50) | 是 | - |
| user_agent | 用户代理 | TEXT | 是 | - |
| tx_id | 区块链交易ID | VARCHAR(100) | 是 | - |
| status | 操作状态（success/failed） | VARCHAR(20) | 否 | - |
| error_message | 错误信息 | TEXT | 是 | - |
| created_at | 操作时间 | TIMESTAMP | 否 | - |

**索引设计：**
- PRIMARY KEY (id)
- INDEX idx_audit_user (user_id)
- INDEX idx_audit_action (action)
- INDEX idx_audit_resource (resource_type, resource_id)
- INDEX idx_audit_created (created_at)
- INDEX idx_audit_status (status)

---

## 表 7.3 系统配置表（system_configs）结构设计

| 字段名 | 描述 | 字段类型 | 是否为空 | 主键/外键 |
|--------|------|----------|----------|-----------|
| id | 自增ID | INT | 否 | 主键 |
| config_key | 配置键 | VARCHAR(100) | 否 | - |
| config_value | 配置值 | TEXT | 否 | - |
| config_type | 配置类型（string/number/boolean/json） | VARCHAR(50) | 否 | - |
| description | 配置描述 | VARCHAR(500) | 是 | - |
| is_editable | 是否可编辑（1-是，0-否） | TINYINT | 否 | - |
| created_at | 创建时间 | TIMESTAMP | 否 | - |
| updated_at | 更新时间 | TIMESTAMP | 否 | - |

**索引设计：**
- PRIMARY KEY (id)
- UNIQUE KEY (config_key)
- INDEX idx_configs_key (config_key)
