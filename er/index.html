系统特性

🔐 安全特性

  • 基于用户名密码的身份认证机制
  • 基于角色的访问控制(RBAC)
  • 密码SHA256哈希存储
  • 区块链不可篡改特性
  • 完整的操作审计日志
  • 患者控制的数据访问权限

⛓️ 区块链特性

  • 基于 Hyperledger Fabric 2.x 构建
  • 所有关键操作写入区块链，保证数据不可篡改
  • MySQL作为缓存层，提供快速查询
  • 支持跨组织数据共享和授权
  • 完整的交易追溯能力

🛠️ 技术栈

  • 后端：Go + Gin + MySQL + Fabric SDK
  • 前端：Vue.js 3 + Element Plus
  • 区块链：Hyperledger Fabric + Go Chaincode
  • 共识算法：Raft
