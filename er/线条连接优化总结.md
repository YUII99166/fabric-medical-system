# ER图线条连接优化总结

## 📋 问题分析

当前功能ER图中存在的线条连接问题：

### 1. 主要问题
- ❌ 线条没有精确连接到实体矩形的边缘
- ❌ 线条没有精确连接到属性椭圆的边缘
- ❌ 连接点是手动估算的，不够精确
- ❌ 当调整布局时，需要手动重新计算所有连接点

### 2. 问题示例

```javascript
// 错误的方式：手动估算连接点
attribute(userX - 350, userY - 300, 160, 80, '姓名');
line(userX - 270, userY - 260, userX - 120, userY - 50);  // 连接点不精确
```

## ✅ 解决方案

### 1. 核心思路

使用数学计算精确确定连接点：
- 计算从实体中心到属性中心的角度
- 根据角度计算实体边缘的交点
- 根据角度计算椭圆边缘的交点
- 连接两个精确的交点

### 2. 实现方法

#### 步骤1：添加边缘计算函数

```javascript
// 计算矩形边缘点
function getRectEdgePoint(rectX, rectY, rectW, rectH, targetX, targetY) {
    const centerX = rectX + rectW / 2;
    const centerY = rectY + rectH / 2;
    const dx = targetX - centerX;
    const dy = targetY - centerY;
    
    if (dx === 0 && dy === 0) return { x: centerX, y: centerY };
    
    const angle = Math.atan2(dy, dx);
    const absAngle = Math.abs(angle);
    
    // 判断交点在哪条边
    if (absAngle < Math.atan2(rectH, rectW)) {
        return { x: rectX + rectW, y: centerY + (rectW / 2) * Math.tan(angle) };
    } else if (absAngle > Math.PI - Math.atan2(rectH, rectW)) {
        return { x: rectX, y: centerY - (rectW / 2) * Math.tan(angle) };
    } else if (angle > 0) {
        return { x: centerX + (rectH / 2) / Math.tan(angle), y: rectY + rectH };
    } else {
        return { x: centerX - (rectH / 2) / Math.tan(angle), y: rectY };
    }
}

// 计算椭圆边缘点
function getEllipseEdgePoint(cx, cy, rx, ry, targetX, targetY) {
    const dx = targetX - cx;
    const dy = targetY - cy;
    
    if (dx === 0 && dy === 0) return { x: cx, y: cy };
    
    const angle = Math.atan2(dy, dx);
    return {
        x: cx + rx * Math.cos(angle),
        y: cy + ry * Math.sin(angle)
    };
}
```

#### 步骤3：批量绘制

```javascript
userAttrs.forEach(attr => {
    // 绘制属性椭圆
    attribute(attr.cx - attr.rx, attr.cy - attr.ry, attr.rx * 2, attr.ry * 2, attr.text, attr.key);
    
    // 计算精确连接点
    const rectEdge = getRectEdgePoint(userX - 150, userY - 80, userW, userH, attr.cx, attr.cy);
    const ellipseEdge = getEllipseEdgePoint(attr.cx, attr.cy, attr.rx, attr.ry, rectEdge.x, rectEdge.y);
    
    // 绘制连接线
    line(rectEdge.x, rectEdge.y, ellipseEdge.x, ellipseEdge.y);
});
```

## 📐 数学原理

### 矩形边缘交点计算
1. 计算从矩形中心到目标点的角度 θ
2. 根据角度判断交点在哪条边：
   - |θ| < arctan(h/w)：右边
   - |θ| > π - arctan(h/w)：左边
   - θ > 0：下边
   - θ < 0：上边
3. 使用三角函数计算精确交点坐标

### 椭圆边缘交点计算
1. 计算从椭圆中心到目标点的角度 θ
2. 使用参数方程：
   - x = cx + rx × cos(θ)
   - y = cy + ry × sin(θ)
