# 管理员查看联盟组织功能ER图描述

## 实体说明

该ER图包含两个核心实体：

1. **管理员实体**：系统管理员，负责整个医疗信息管理系统的运维和管理工作。主要属性包括用户ID（主键）、姓名、角色、组织ID和管理权限等。管理员拥有查看和管理所有联盟组织的权限，可以监控联盟网络的运行状态。

2. **联盟组织实体**：参与区块链联盟的医疗机构组织，如医院、药店、保险公司等。主要属性包括组织ID（主键）、组织名称、组织类型、域名、证书状态、状态、加入时间、联系方式、节点数量和管理员数等。每个组织代表区块链网络中的一个参与方，拥有独立的节点和证书体系。

## 业务流程

管理员通过联盟组织查看功能对区块链网络中的所有参与方进行监控和管理。具体流程如下：

1. **组织信息查看**：管理员可以查看所有联盟组织的详细信息（1:n关系），包括组织名称、类型、域名、证书状态、节点数量、管理员数等。这些信息帮助管理员全面了解联盟网络的组成结构和各参与方的基本情况。

2. **组织状态监控**：管理员可以实时监控各组织的运行状态，包括证书是否有效、节点是否在线、组织是否处于活跃状态等。当某个组织出现异常（如证书过期、节点离线）时，管理员可以及时发现并采取相应措施，确保联盟网络的稳定运行。

3. **组织统计分析**：管理员可以查看各组织的节点数量、管理员数量等统计信息，分析联盟网络的规模和分布情况。这些数据有助于管理员评估网络的去中心化程度，优化资源配置，制定网络扩展计划。

## 区块链技术保障

该功能基于Hyperledger Fabric区块链联盟架构，实现了多组织协作的医疗信息管理网络。每个联盟组织都是区块链网络中的独立参与方，拥有自己的节点、证书和管理员。组织的加入、退出、证书更新等关键操作都会被记录到区块链上，确保联盟网络的变更历史可追溯、不可篡改。管理员通过查看组织信息，可以了解整个联盟网络的拓扑结构和运行状态，但无法单方面修改其他组织的配置，这体现了区块链去中心化的特性。每个组织的证书由CA（证书颁发机构）签发，基于PKI体系确保了组织身份的真实性和通信的安全性。联盟组织的域名信息用于网络通信和节点发现，节点数量反映了组织在网络中的参与程度。这种多组织联盟架构既保证了数据的共享和互通，又确保了各参与方的独立性和隐私保护，为跨机构的医疗信息协作提供了可信的技术基础。
