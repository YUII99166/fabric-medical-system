## 技术要点

### 1. 菱形连接点计算
**水平方向**:
- 左角: `{ x: relX - relW/2, y: relY }`
- 右角: `{ x: relX + relW/2, y: relY }`

**垂直方向**:
- 上角: `{ x: relX, y: relY - relH/2 }`
- 下角: `{ x: relX, y: relY + relH/2 }`

### 2. 连接线宽度统一
所有关系连接线的宽度统一设置为 3px：
```javascript
function line(x1, y1, x2, y2) {
    g.strokeStyle = '#000';
    g.lineWidth = 3;  // 从 2 改为 3
    g.beginPath();
    g.moveTo(x1, y1);
    g.lineTo(x2, y2);
    g.stroke();
}
```

### 3. 基数标注位置
基数标注（1, n）放在连接线的中点位置：
```javascript
const midX = (startX + endX) / 2;
const midY = (startY + endY) / 2;
label('1', midX, midY - 30, 46, true);
```
