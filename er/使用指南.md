# ER图文档使用指南

## 📖 概述

本文件夹包含医疗信息管理系统的完整ER图文档，包括实体定义、功能流程图和交互式查看器。

## 🚀 快速开始

### 1. 浏览所有ER图
打开 **[index.html](./index.html)** 文件，这是一个美观的可视化索引页面，包含：
- 系统统计信息
- 8个核心实体的文档链接
- 7个功能ER图的可视化展示
- 系统特性说明

### 2. 查看单个实体详情
打开 **[entity-er-viewer.html](./entity-er-viewer.html)** 文件，这是一个交互式查看器：
- 下拉选择任意实体
- 实时渲染该实体的完整ER图（包含所有属性）
- 支持下载PNG图片
- 主键属性用双线椭圆标识

### 3. 阅读实体文档
每个实体都有对应的Markdown文档（01-08开头），包含：
- Mermaid格式的ER图
- 详细的属性说明表格
- 真实的示例数据（JSON格式）
- 业务规则和约束
- 索引设计
- SQL查询示例

### 4. 查看功能ER图
功能ER图展示具体业务流程中涉及的实体关系：
- `feature-er-doctor-create-prescription.html` - 医生创建病历
- `feature-er-doctor-add-supplement.html` - 医生添加补充记录
- `feature-er-doctor-request-access.html` - 医生申请授权
- `feature-er-patient-approve-access.html` - 患者审批授权
- `feature-er-patient-own-prescriptions.html` - 患者拥有病历
- `feature-er-patient-create-drug-order.html` - 患者下单药品
- `feature-er-patient-create-insurance-claim.html` - 患者创建保险理赔

所有功能ER图都支持：
- 下载PNG图片
- 复制到剪贴板
- Canvas高清渲染

## 🎯 使用场景

### 场景1：了解系统整体架构
1. 打开 `index.html` 浏览系统概览
2. 阅读 `00-global-er-diagram.md` 了解全局关系
3. 查看各个实体的Markdown文档

### 场景2：开发数据库表结构
1. 打开 `entity-er-viewer.html` 查看实体属性
2. 阅读对应的Markdown文档获取详细字段说明
3. 参考示例数据和业务规则

### 场景3：理解业务流程
1. 打开 `index.html` 找到相关功能ER图
2. 点击查看具体的功能ER图HTML文件
3. 下载图片用于文档或演示

### 场景4：编写技术文档
1. 使用 `entity-er-viewer.html` 导出实体ER图
2. 使用功能ER图HTML文件导出流程图
3. 引用Markdown文档中的示例数据

## 🛠️ 技术说明

### HTML文件特性
- 使用Canvas API绘制，支持高清导出
- 纯前端实现，无需服务器
- 支持下载PNG和复制到剪贴板
- 响应式设计，适配不同屏幕

### Markdown文件特性
- 使用Mermaid语法绘制ER图
- 在GitHub上自动渲染
- 可在VS Code中使用Mermaid插件预览
- 包含完整的JSON示例数据

### 图表说明
- **矩形框**：实体
- **双层矩形框**：弱实体
- **菱形**：关系
- **椭圆**：属性
- **双线椭圆**：主键属性
- **1, n, m**：基数标注

## 📝 维护说明

### 更新实体定义
1. 修改对应的Markdown文档
2. 更新 `entity-er-viewer.html` 中的ENTITIES对象
3. 如有新增实体，同步更新 `index.html`

### 更新功能ER图
1. 修改对应的HTML文件中的绘图代码
2. 调整布局和属性显示
3. 更新说明文字

### 添加新功能ER图
1. 复制现有的功能ER图HTML文件
2. 修改标题和绘图内容
3. 在 `index.html` 中添加卡片链接
