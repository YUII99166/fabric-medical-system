# 医生添加补充诊疗记录功能ER图描述

医生添加补充诊疗记录功能有三个实体：医生、补充记录和病历。一个医生可以添加多个补充记录，多个补充记录可以关联到同一个病历。医生的属性有：用户ID、姓名、角色、组织、科室、职称、区块链ID等。补充记录的属性有：补充ID、诊断、医嘱、现病史、体格检查、复诊时间、医生ID等。病历的属性有：病历ID、病历编号、患者姓名、区块链交易ID、医生姓名、诊断、创建时间等。

该ER图展示了医生添加补充诊疗记录的业务流程：医生在患者复诊或后续诊疗过程中，针对已有病历添加补充诊疗记录。补充记录记录了患者的复诊信息、病情变化、新的诊断结果和医嘱等内容，并通过"添加"关系关联到医生，通过"包含"关系关联到对应的病历。这种设计既保证了医疗责任的可追溯性，又为患者提供了完整的诊疗历史记录，支持医生做出更准确的诊疗决策。

该功能采用Hyperledger Fabric区块链技术，实现了补充诊疗记录的不可篡改和可追溯。每次医生添加补充记录时，系统都会将记录信息同步到区块链上，生成唯一的区块链交易ID。医生的区块链ID用于在区块链网络中标识医生身份，确保操作的真实性和不可否认性。病历中包含的区块链交易ID可以用于在区块链浏览器中查看完整的诊疗记录变更历史。这种设计确保了补充记录一旦添加就无法被篡改或删除，保护了医疗数据的完整性和真实性。区块链的分布式账本特性还保证了诊疗记录在多个医疗机构节点间的一致性，支持跨机构的诊疗信息共享。同时，区块链的时间戳机制准确记录了每次补充记录的添加时间，为医疗纠纷处理和医疗质量评估提供了可靠的证据支持。
