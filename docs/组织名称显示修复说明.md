# 组织名称显示修复说明

## 问题描述

在用户管理页面中，部分用户的组织信息显示为"-"，但实际上这些用户是有组织的（例如华佗属于温江社区医疗中心）。

## 问题原因

1. 数据库中的`users`表有两个字段：
   - `organization`: 存储组织的MSPID（如`WenjinMSP`）
   - `organization_name`: 存储组织的显示名称（如`温江社区医疗中心`）

2. 部分用户在创建时，只设置了`organization`字段，但`organization_name`字段为空

3. 前端页面直接显示`organization_name`，导致显示为"-"

## 解决方案

### 1. 前端修复（已完成）

在用户列表和删除用户页面中，添加了`getOrganizationDisplayName`方法：
- 如果`organization_name`有值，直接使用
- 如果`organization_name`为空，根据`organization` MSPID自动映射到显示名称

映射关系：
- `TaobaoMSP` → `协和医院`
- `JDMSP` → `301医院`
- `WenjinMSP` → `温江社区医疗中心`
- `RegCenterMSP` → `监管中心`

### 2. 数据库修复（可选）

如果希望彻底修复数据库中的数据，可以执行以下SQL脚本：

```bash
# 进入MySQL容器
docker exec -it mysql bash

# 登录MySQL
mysql -u root -p123456

# 执行修复脚本
source /path/to/fix_organization_names.sql
```

或者直接在MySQL中执行：

```sql
USE fabric;

UPDATE users SET organization_name = '协和医院' 
WHERE organization = 'TaobaoMSP' AND (organization_name IS NULL OR organization_name = '');

UPDATE users SET organization_name = '301医院' 
WHERE organization = 'JDMSP' AND (organization_name IS NULL OR organization_name = '');

UPDATE users SET organization_name = '温江社区医疗中心' 
WHERE organization = 'WenjinMSP' AND (organization_name IS NULL OR organization_name = '');

UPDATE users SET organization_name = '监管中心' 
WHERE organization = 'RegCenterMSP' AND (organization_name IS NULL OR organization_name = '');
```

### 3. 预防措施

注册新用户时，后端API已经正确处理了`organization_name`字段，新注册的用户不会出现此问题。

## 影响范围

- ✅ 用户管理页面（`/account/list`）
- ✅ 删除用户页面（`/account/delete`）
- ✅ 用户详情页面（已有正确的组织信息显示）
