# 登录注册错误提示修复说明

## 问题描述

用户反映在登录和注册时，各种错误（密码错误、用户名已存在等）都没有提示信息。

## 问题原因

前端 `request.js` 的响应拦截器在处理错误响应时，没有正确提取后端返回的错误消息。

### 后端响应格式

后端统一使用以下格式返回响应：

```json
{
  "code": 200,     // HTTP状态码
  "msg": "成功",   // 消息
  "data": {}       // 数据
}
```

错误响应示例：

```json
{
  "code": 400,
  "msg": "用户名已存在，请更换用户名",
  "data": null
}
```

### 原问题

原来的拦截器代码：

```javascript
service.interceptors.response.use(
  response => {
    const res = response.data
    if (res.code !== undefined) {
      if (res.code !== 200) {
        return Promise.reject(new Error(res.msg || res.data || 'Error'))
      }
    }
  },
  error => {
    // 错误处理不完善
  }
)
```

问题：
1. 成功响应（HTTP 200）但业务失败（code 400）时，错误消息能正确提取
2. 但 HTTP 错误响应（如 400、401）会进入 error 回调，原来的处理逻辑不够完善

## 修复方案

### 1. 优化响应拦截器

修改 `fabric-mims-main/application/web/src/utils/request.js`：

```javascript
service.interceptors.response.use(
  response => {
    const res = response.data
    console.log('拦截器收到响应:', res)
    
    if (res.code !== undefined) {
      if (res.code !== 200) {
        // 错误响应：提取 msg 字段作为错误消息
        const errorMsg = res.msg || res.data || 'Error'
        console.error('API错误:', errorMsg)
        return Promise.reject(new Error(errorMsg))
      } else {
        // 成功响应
        return res
      }
    } else {
      return res
    }
  },
  error => {
    console.error('请求错误:', error)
    
    if (error.response === undefined) {
      // 网络错误
      return Promise.reject(new Error('网络连接失败，请检查网络后重试'))
    } else {
      // 服务器返回错误响应
      const res = error.response.data
      let errorMsg = '请求失败'
      
      // 优先使用 msg 字段
      if (res && res.msg) {
        errorMsg = res.msg
      } else if (res && res.data && typeof res.data === 'string') {
        errorMsg = res.data
      } else if (error.message) {
        errorMsg = error.message
      }
      
      console.error('错误消息:', errorMsg)
      return Promise.reject(new Error(errorMsg))
    }
  }
)
```

### 2. 前端已有的错误处理

登录页面（`fabric-mims-main/application/web/src/views/login/index.vue`）已经有完善的错误处理逻辑：

#### 登录错误处理

```javascript
.catch((error) => {
  const errorMsg = error.message || error.toString()
  if (errorMsg.includes('用户名或密码错误') || errorMsg.includes('用户不存在')) {
    this.$message.error('用户名或密码错误，请检查后重试')
  } else if (errorMsg.includes('网络') || errorMsg.includes('timeout')) {
    this.$message.error('网络连接失败，请检查网络后重试')
  } else if (errorMsg.includes('服务器') || errorMsg.includes('500')) {
    this.$message.error('服务器错误，请稍后重试')
  } else {
    this.$message.error(errorMsg || '登录失败，请重试')
  }
})
```

#### 注册错误处理

```javascript
.catch((error) => {
  const errorMsg = error.message || error.toString()
  if (errorMsg.includes('用户名已存在') || errorMsg.includes('already exists')) {
    this.$message.error('该用户名已被注册，请更换用户名')
  } else if (errorMsg.includes('参数') || errorMsg.includes('空值')) {
    this.$message.error('请填写完整的注册信息')
  } else if (errorMsg.includes('组织')) {
    this.$message.error('请选择所属组织')
  } else if (errorMsg.includes('网络') || errorMsg.includes('timeout')) {
    this.$message.error('网络连接失败，请检查网络后重试')
  } else if (errorMsg.includes('区块链') || errorMsg.includes('blockchain')) {
    this.$message.error('区块链服务暂时不可用，请稍后重试或联系管理员')
  } else {
    this.$message.error(errorMsg || '注册失败，请重试')
  }
})
```
