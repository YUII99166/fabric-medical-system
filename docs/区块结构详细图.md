## 7. 完整数据流程

```mermaid
sequenceDiagram
    participant Doctor as 👨‍⚕️ 华佗医生
    participant Frontend as 🖥️ 前端
    participant Backend as 🔧 后端服务器
    participant Chaincode as 📝 链码
    participant Peer as 🔗 Peer节点
    participant Orderer as 📋 Orderer节点
    participant Blockchain as ⛓️ 区块链
    participant WorldState as 🌍 世界状态
    
    Doctor->>Frontend: 查看科比的病历
    Frontend->>Backend: POST /api/v2/recordPrescriptionAccess
    Backend->>Chaincode: 调用 recordPrescriptionAccess
    
    Note over Chaincode: 1. 创建访问日志对象<br/>2. 序列化为JSON<br/>3. 创建复合主键
    
    Chaincode->>Peer: PutState(key, value)
    
    Note over Peer: 生成读写集<br/>Write Set
    
    Peer->>Backend: 返回背书响应
    Backend->>Orderer: 提交交易
    
    Note over Orderer: 1. 验证交易<br/>2. 排序<br/>3. 打包成区块
    
    Orderer->>Peer: 广播新区块
    
    Note over Peer: 1. 验证区块<br/>2. 提交到账本<br/>3. 更新世界状态
    
    Peer->>Blockchain: 追加区块
    Peer->>WorldState: 更新状态
    
    WorldState-->>Backend: 返回TxID
    Backend-->>Frontend: 返回成功
    Frontend-->>Doctor: 显示记录成功
    
    Note over Blockchain: 数据永久存储<br/>不可篡改
```

## 10. 关键要点总结

### 区块结构三大组成部分:

1. **区块头 (Block Header)**
   - 区块号
   - 前区块哈希 (形成链)
   - 数据哈希 (默克尔根)
   - 时间戳

2. **区块数据 (Block Data)**
   - 包含多个交易
   - 每个交易包含读写集
   - 写集中存储Key-Value对
   - Value以JSON格式存储

3. **区块元数据 (Block Metadata)**
   - 签名信息
   - 验证结果
   - 提交信息

### 数据存储格式:

- **格式**: JSON字符串
- **大小**: 约450字节
- **编码**: UTF-8
- **结构**: Go结构体 → JSON → 字节数组

### 不可篡改保证:

- 哈希链：修改任何数据会导致哈希不匹配
- 默克尔树：快速验证数据完整性
- 数字签名：验证交易来源
- 分布式存储：多节点备份
