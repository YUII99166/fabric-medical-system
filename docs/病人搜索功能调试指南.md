# 病人搜索功能调试指南

## 问题描述

医生端通过病人姓名查询病历时，输入名字后没有查询到信息。

## 当前状态

- 后端代码已修复（错误响应格式已统一）
- 前端搜索逻辑已实现多关键词尝试
- 链码匹配逻辑已支持多种匹配方式
- 用户确认区块链中有科比的病历数据

## 可能的原因

### 1. 后端服务未重启

修复后的代码需要重启后端服务才能生效。

### 2. 前端请求未发送到后端

浏览器可能缓存了旧的代码，或者请求被拦截。

### 3. 病历数据中的患者姓名格式不匹配

病历中的患者姓名可能是以下格式之一：
- `科比`（纯姓名）
- `病人-科比`（带前缀）
- 其他格式

### 4. 医生ID未正确获取

医生的 account_id 可能是"未同步到区块链"。

## 紧急排查步骤（按优先级）

### 步骤 0：重启后端服务（最重要！）

修复后的代码需要重启后端服务才能生效：

```bash
# 停止后端服务（Ctrl+C）
# 然后重新启动
cd fabric-mims-main/application/server
go run main.go
```

### 步骤 1：检查浏览器网络请求（最关键！）

1. 打开浏览器开发者工具（F12）
2. 切换到 **Network（网络）** 标签
3. 输入患者姓名（例如：科比）并点击搜索
4. 查看是否有 `/queryPrescriptionsByPatient` 请求

**如果没有看到请求：**
- 前端代码可能有问题，或者浏览器缓存了旧代码
- 尝试硬刷新页面（Ctrl+Shift+R 或 Ctrl+F5）
- 清除浏览器缓存后重新加载

**如果看到请求，检查请求参数：**
```json
{
  "search_key": "科比",
  "doctor_id": "医生的account_id"
}
```

**检查响应：**
- 如果返回空数组 `[]`，说明没有匹配的病历
- 如果返回错误，查看错误消息

### 步骤 2：查看后端日志

在后端控制台查看是否有 `QueryPrescriptionsByPatient` 的日志：

**期望看到的日志：**
```

QueryPrescriptionsByPatient - 将尝试搜索关键词: [科比 病人-科比]
QueryPrescriptionsByPatient - 尝试搜索关键词 1/2: 科比
QueryPrescriptionsByPatient - 搜索关键词 '科比' 返回 X 条记录
```

**如果没有看到这些日志：**
- 说明请求没有到达后端
- 检查前端API地址配置是否正确
- 检查后端服务是否正常运行

### 步骤 3：检查科比病历的患者姓名格式

1. 以医生身份登录
2. 进入"我的病历"页面
3. 找到科比的病历
4. 查看患者姓名字段的确切内容

**可能的格式：**
- `科比`
- `病人-科比`
- `Kobe`
- 其他格式

然后在搜索框中输入完全相同的名字进行搜索。

## 常见问题解决

### 问题 1：返回空数组

**现象：**
```json
{
  "code": 200,
  "msg": "成功",
  "data": []
}
```

**原因：** 区块链中没有匹配的病历数据

**解决方案：**

1. **创建测试病历**

以医生身份登录，创建一个病历：
- 患者姓名：输入要搜索的患者姓名
- 填写其他必填字段
- 提交

2. **检查病历是否创建成功**

在"我的病历"页面查看是否有刚创建的病历。

3. **再次搜索**

返回病人搜索页面，输入患者姓名搜索。

### 问题 2：医生ID为"未同步到区块链"

**现象：** 后端日志显示
```
QueryPrescriptionsByPatient - 医生ID未同步，使用通用搜索模式
```

**原因：** 医生账号没有同步到区块链

**解决方案：**

1. **重新登录**

退出登录，重新登录，系统会自动同步 account_id。

2. **手动同步**

在用户管理页面，找到自己的账号，点击"同步到区块链"。

### 问题 3：搜索关键词格式不匹配

**现象：** 搜索"周杰伦"没结果，但搜索"病人-周杰伦"有结果

**原因：** 病历中的患者姓名是"病人-周杰伦"，但搜索逻辑没有正确处理

**解决方案：**

前端已经实现了自动尝试多个关键词的逻辑，应该能自动处理。如果还是不行，检查：

1. 前端代码中的 `trySearchWithKeys` 方法是否正常执行
2. 浏览器控制台是否有错误日志

### 问题 4：区块链查询失败

**现象：** 后端日志显示
```
QueryPrescriptionsByPatient - 搜索关键词 'xxx' 第1次尝试失败: xxx
```

**原因：** 区块链网络连接失败或链码错误

**解决方案：**

1. **检查 Docker 容器状态**

```bash
docker ps
```

确保所有区块链节点都在运行。

2. **重启区块链网络**

```bash
cd fabric-mims-main/network
./restart-blockchain.sh
```

3. **检查链码版本**

确保链码已正确安装和升级。
