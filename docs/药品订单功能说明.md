# 病历页面药品订单信息功能说明

## 功能概述
在病历列表页面的每个病历卡片上添加"药品订单"信息项，显示该病历关联的药品订单数量。点击"药品订单"可以弹出对话框查看该病历的所有药品订单详情。

## 修改的文件

### 1. 前端页面
- `fabric-mims-main/application/web/src/views/prescription/list/index.vue` - 病历列表页面
- `fabric-mims-main/application/web/src/views/prescription/mine/index.vue` - 我的病历页面

### 2. 主要修改内容

#### 导入药品订单API
```javascript
import { queryDrugOrderList } from '@/api/drugOrder'
```

#### 添加数据字段
```javascript
data() {
  return {
    // ... 其他字段
    drugOrders: [], // 当前病历的药品订单列表
    loadingOrders: false, // 加载订单状态
    drugOrderDialogVisible: false, // 药品订单对话框
    allDrugOrders: [] // 所有药品订单（用于快速查找）
  }
}
```

#### 在created钩子中加载所有药品订单
```javascript
created() {
  // ... 其他初始化代码
  
  // 加载所有药品订单
  this.loadAllDrugOrders()
}
```

#### 新增方法

**loadAllDrugOrders()** - 加载所有药品订单
```javascript
loadAllDrugOrders() {
  queryDrugOrderList({}).then(response => {
    const orderList = response && response.code === 200 ? response.data : (Array.isArray(response) ? response : [])
    this.allDrugOrders = orderList || []
  }).catch(err => {
    console.error('加载药品订单失败:', err)
    this.allDrugOrders = []
  })
}
```

**getDrugOrderCount(prescriptionId)** - 获取指定病历的药品订单数量
```javascript
getDrugOrderCount(prescriptionId) {
  return this.allDrugOrders.filter(order => order.prescription === prescriptionId).length
}
```

**showDrugOrders(prescription)** - 显示药品订单对话框
```javascript
showDrugOrders(prescription) {
  this.selectedPrescription = prescription
  this.drugOrders = this.allDrugOrders.filter(order => order.prescription === prescription.id)
  this.drugOrderDialogVisible = true
}
```

**getOrderStatusType(status)** - 获取订单状态类型（用于el-tag的type属性）
```javascript
getOrderStatusType(status) {
  const statusMap = {
    'pending': 'warning',
    'processing': 'info',
    'completed': 'success',
    'cancelled': 'danger'
  }
  return statusMap[status] || 'info'
}
```

**getOrderStatusText(status)** - 获取订单状态文本（中文显示）
```javascript
getOrderStatusText(status) {
  const statusMap = {
    'pending': '待处理',
    'processing': '处理中',
    'completed': '已完成',
    'cancelled': '已取消'
  }
  return statusMap[status] || status
}
```

## 界面展示

### 1. 病历卡片上的药品订单信息项
在每个病历卡片的信息区域添加了"药品订单"项：
- 显示购物车图标
- 显示"药品订单"文字
- 如果有订单，显示订单数量徽章
- 点击后弹出药品订单对话框
- 使用 `@click.stop` 阻止事件冒泡，避免触发卡片的点击事件

### 2. 药品订单对话框
点击"药品订单"后弹出的对话框包含：

**顶部信息栏**（紫色渐变背景）：
- 病历ID
- 患者姓名
- 诊断信息

**订单列表**（有订单时）：
- 每个订单显示为一个卡片
- 订单编号和状态标签
- 订单详细信息：
  - 订单ID
  - 药品名称（高亮显示）
  - 数量
  - 药店名称
  - 创建时间

**无订单提示**（无订单时）：
- 显示信息图标
- 提示"该病历暂无药品订单"

## 样式特点
- 药品订单链接使用主题色，鼠标悬停时颜色变浅并有位移动画
- 订单数量徽章显示在右侧
- 订单卡片采用左侧蓝色边框设计
- 鼠标悬停订单卡片时有高亮和上浮效果
- 订单状态使用不同颜色的标签区分
- 响应式布局，适配不同屏幕尺寸

## 数据流程
1. 页面加载时，同时加载病历列表和所有药品订单
2. 药品订单存储在 `allDrugOrders` 数组中
3. 每个病历卡片通过 `getDrugOrderCount()` 方法实时计算该病历的订单数量
4. 点击"药品订单"时，通过 `showDrugOrders()` 方法过滤出当前病历的订单并显示对话框

## 性能优化
- 只在页面加载时查询一次所有药品订单
- 使用前端过滤而不是每次都调用API
- 订单数量通过计算属性实时计算，无需额外存储

## 后端支持
使用现有的药品订单查询接口：
- API路径：`/queryDrugOrderList`
- 方法：POST
- 参数：空对象 `{}`（查询所有订单）
- 返回：药品订单列表

## 注意事项
1. 药品订单通过 `prescription` 字段与病历ID关联
2. 订单状态包括：pending（待处理）、processing（处理中）、completed（已完成）、cancelled（已取消）
3. 点击"药品订单"使用 `@click.stop` 阻止事件冒泡，不会触发卡片的点击跳转
4. 如果API调用失败，`allDrugOrders` 会被设置为空数组，不影响页面其他功能
5. 病历卡片的点击事件仍然保持原有功能（跳转到详情页面）
