# 病人搜索连接问题修复

## 问题描述

医生端搜索患者病历时，浏览器控制台显示 `ERR_CONNECTION_REFUSED` 错误，请求无法到达后端。

## 问题原因

`access.js` 文件中直接使用了原始的 `axios` 实例，而不是使用项目统一的 `request.js`：

```javascript
// 错误的写法
import axios from 'axios'
const API_BASE = 'http://localhost:8888/api/v2'

export function queryPrescriptionsByPatient(data) {
  return axios.post(`${API_BASE}/queryPrescriptionsByPatient`, data)
    .then(res => res.data)
}
```

这导致：
1. 没有使用 Vue 的代理配置（`vue.config.js` 中的 proxy）
2. 直接请求 `http://localhost:8888`，可能被浏览器的 CORS 策略阻止
3. 没有使用统一的响应拦截器处理错误

## 解决方案

修改 `access.js`，使用统一的 `request` 实例：

```javascript
// 正确的写法
import request from '@/utils/request'

export function queryPrescriptionsByPatient(data) {
  return request({
    url: '/queryPrescriptionsByPatient',
    method: 'post',
    data
  })
}
```

## 为什么要使用统一的 request 实例？

### 1. 使用代理配置

`vue.config.js` 中配置了代理：

```javascript
proxy: {
  '/api': {
    target: "http://127.0.0.1:8888/",
    changeOrigin: true,
  }
}
```

使用 `request` 实例时，请求会通过代理转发：
- 前端请求：`http://localhost:9528/api/v2/queryPrescriptionsByPatient`
- 代理转发到：`http://127.0.0.1:8888/api/v2/queryPrescriptionsByPatient`

这样可以避免 CORS 跨域问题。

### 2. 统一的错误处理

`request.js` 中配置了响应拦截器：

```javascript
service.interceptors.response.use(
  response => {
    const res = response.data
    if (res.code !== 200) {
      const errorMsg = res.msg || res.data || 'Error'
      return Promise.reject(new Error(errorMsg))
    }
    return res
  },
  error => {
    // 统一的错误处理
    return Promise.reject(error)
  }
)
```

这样可以统一处理所有 API 的错误响应。

### 3. 统一的配置

`request.js` 中配置了：
- `baseURL`: 从环境变量读取
- `timeout`: 超时时间
- 请求/响应拦截器

所有 API 都使用相同的配置，便于维护。
