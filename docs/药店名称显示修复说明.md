# 药店名称显示修复说明

## 问题描述

健康档案页面的药品订单中，药店名称都显示为"未知药店"，无法正常显示药店名称。

## 问题原因

### accountCache.js 的数据结构

`accountCache.js` 返回的 `accountMap` 是一个对象映射，结构如下：

```javascript
{
  "account_id_1": {
    name: "药店-老百姓大药房",
    username: "pharmacy1",
    role: "药店",
    organization_name: "老百姓大药房",
    organization: "PharmacyMSP"
  },
  "account_id_2": {
    name: "医生-张三",
    username: "doctor1",
    role: "医生",
    organization_name: "协和医院",
    organization: "TaobaoMSP"
  }
}
```

### 错误的实现

健康档案页面的 `getDrugstoreName` 方法错误地将 `accountMap[drugstoreId]` 当作字符串使用：

```javascript
// ❌ 错误的实现
getDrugstoreName(drugstoreId) {
  const accountName = this.accountMap[drugstoreId]  // 这是一个对象，不是字符串
  
  if (accountName) {
    if (/药店/.test(accountName)) {  // 对象无法进行正则匹配
      return accountName.replace(/^药店-/, '')
    }
  }
  return '未知药店'
}
```

### 问题分析

1. `this.accountMap[drugstoreId]` 返回的是一个对象，不是字符串
2. 对对象进行正则匹配 `/药店/.test(accountName)` 会失败
3. 对象的 `replace` 方法不存在，导致返回 "未知药店"

## 修复方案

### 修改文件

`fabric-mims-main/application/web/src/views/patient/health-profile/index.vue`

### 修复后的实现

```javascript
// ✅ 正确的实现
getDrugstoreName(drugstoreId) {
  if (!drugstoreId) {
    return '未知药店'
  }
  
  const account = this.accountMap[drugstoreId]
  
  if (account) {
    // accountMap 中的值是对象，包含 name, username, role, organization_name 等
    const accountName = account.name || account.account_name || account.username
    
    if (accountName) {
      // 如果账户名包含"药店"，去掉前缀和后缀
      if (/药店/.test(accountName)) {
        return accountName.replace(/^药店-/, '').replace(/-药店$/, '')
      } else {
        // 如果不包含"药店"，直接返回账户名
        return accountName
      }
    }
  }
  
  // 如果找不到账户名，返回"未知药店"
  console.warn('⚠️ 找不到药店账户，ID:', drugstoreId, '账户映射表:', this.accountMap)
  return '未知药店'
}
```

### 关键改动

1. **正确获取账户对象**
   ```javascript
   const account = this.accountMap[drugstoreId]  // 获取账户对象
   ```

2. **从对象中提取名称**
   ```javascript
   const accountName = account.name || account.account_name || account.username
   ```

3. **对字符串进行处理**
   ```javascript
   if (/药店/.test(accountName)) {  // 现在是对字符串进行匹配
     return accountName.replace(/^药店-/, '')
   }
   ```

## 对比：病历详情页面的正确实现

病历详情页面的 `getPharmacyName` 方法已经是正确的实现：

```javascript
// ✅ 病历详情页面的正确实现
getPharmacyName(pharmacyId) {
  if (!pharmacyId) return '未知药店'
  const pharmacy = this.accountMap[pharmacyId]
  if (pharmacy) {
    return pharmacy.organization_name || pharmacy.name || pharmacyId
  }
  return pharmacyId
}
```

这个实现正确地：
1. 获取账户对象：`const pharmacy = this.accountMap[pharmacyId]`
2. 从对象中提取名称：`pharmacy.organization_name || pharmacy.name`

## 注意事项

### accountMap 的数据结构

使用 `accountCache.js` 时，记住 `accountMap` 的值是对象，不是字符串：

```javascript
// ❌ 错误用法
const name = accountMap[id]  // 这是一个对象
if (name.includes('药店')) { ... }  // 错误！

// ✅ 正确用法
const account = accountMap[id]  // 获取账户对象
const name = account.name  // 提取名称字段
if (name.includes('药店')) { ... }  // 正确！
```

### 可用的字段

账户对象包含以下字段：
- `name` - 账户名称（如 "药店-老百姓大药房"）
- `username` - 用户名（如 "pharmacy1"）
- `role` - 角色（如 "药店"）
- `organization_name` - 组织名称（如 "老百姓大药房"）
- `organization` - 组织ID（如 "PharmacyMSP"）

### 推荐用法

根据不同场景选择合适的字段：

```javascript
// 显示药店名称（推荐使用 organization_name）
const pharmacyName = account.organization_name || account.name

// 显示医生名称（推荐使用 name）
const doctorName = account.name

// 显示用户名（用于登录等场景）
const username = account.username
```
