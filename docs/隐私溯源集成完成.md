# 隐私溯源功能集成完成

## 功能概述

隐私溯源功能已完成开发和集成，实现了病历访问的自动记录和查询功能。所有访问记录同时存储在区块链（不可篡改）和MySQL（快速查询）中。

## 功能特性

1. **自动记录访问**
   - 管理员或医生查看病人病历时，自动记录访问日志
   - 记录访问者信息、访问时间、IP地址等
   - 患者本人查看自己的病历不记录

2. **双存储架构**
   - 区块链存储：保证数据不可篡改，提供审计追溯
   - MySQL存储：提供快速查询，优化用户体验
   - 读取策略：优先从MySQL读取，失败时从区块链读取

3. **患者隐私保护**
   - 患者可随时查看谁访问了自己的病历
   - 显示访问者姓名、角色、组织、时间等详细信息
   - 提供统计数据：总访问次数、不同访问者数量、最近7天访问

## 部署步骤

### 方式一：使用一键部署脚本（推荐）

**Linux/Mac:**
```bash
cd fabric-mims-main/scripts
chmod +x deploy-access-trace.sh
./deploy-access-trace.sh
```

**Windows:**
```cmd
cd fabric-mims-main\scripts
deploy-access-trace.bat
```

### 方式二：手动部署

1. **打包 chaincode**
```bash
cd fabric-mims-main/chaincode
GO111MODULE=on go mod vendor
```

2. **部署 chaincode**
```bash
cd ../network
./network.sh deployCC -ccn medical -ccp ../chaincode -ccl go
```

3. **重启后端服务器**
```bash
cd ../application/server
go run main.go
```

## 技术实现

### 后端API

1. **RecordPrescriptionAccess** - 记录访问
   - 路径：`POST /api/v2/recordPrescriptionAccess`
   - 功能：记录病历访问到区块链和MySQL

2. **GetMyAccessLogs** - 查询日志
   - 路径：`POST /api/v2/getMyAccessLogs`
   - 功能：查询患者的访问日志

3. **GetAccessStatistics** - 统计数据
   - 路径：`GET /api/v2/getAccessStatistics`
   - 功能：获取访问统计信息

### Chaincode函数

1. **recordPrescriptionAccess** - 记录到区块链
   - 参数：logID, prescriptionID, prescriptionNo, patientID, patientName, accessorID, accessorName, accessorRole, accessorOrg, accessorOrgName, accessType, accessReason
   - 返回：交易ID

2. **queryAccessLogsByPatient** - 从区块链查询
   - 参数：patientID
   - 返回：访问日志列表

### 数据库表

**prescription_access_logs**
- log_id: 日志ID（唯一）
- prescription_id: 病历ID
- prescription_no: 病历编号
- patient_id: 患者ID
- patient_name: 患者姓名
- accessor_id: 访问者ID
- accessor_name: 访问者姓名
- accessor_role: 访问者角色
- accessor_organization: 访问者组织MSPID
- accessor_organization_name: 访问者组织名称
- access_type: 访问类型（view/edit/download）
- access_reason: 访问原因
- ip_address: IP地址
- user_agent: 浏览器信息
- tx_id: 区块链交易ID
- accessed_at: 访问时间

## 前端页面

**隐私溯源页面** (`/prescription/access-trace`)
- 位置：患者主页 → 隐私溯源
- 功能：
  - 显示统计卡片（总访问次数、不同访问者、最近7天访问）
  - 时间线展示访问记录
  - 显示访问者信息、访问时间、IP地址等
  - 支持分页查询

## 注意事项

1. **首次部署**
   - 必须重新部署 chaincode
   - 必须重启后端服务器
   - 前端无需重新编译（热更新）

2. **数据一致性**
   - 区块链为主要数据源（不可篡改）
   - MySQL为查询缓存（可重建）
   - 如果MySQL数据丢失，可以从区块链重新同步

3. **性能优化**
   - 查询优先使用MySQL（毫秒级）
   - 区块链查询作为备份（秒级）
   - 支持分页，避免一次加载过多数据
