                                    TxID 生成过程

    ┌──────────────┐         ┌──────────────┐              ┌──────────────┐
    │   Nonce      │    +    │   Creator    │   ──SHA256──>│    TxID      │
    │  (24字节)    │         │ (X.509证书)  │              │  (32字节)    │
    └──────────────┘         └──────────────┘              └──────────────┘
         随机数              交易发起者身份                  交易唯一标识
    a1b2c3d4e5f6...      TaobaoMSP + 证书              efc0b928b2e9f817...

                                  区块链连接示意

  ┌─────────┐        ┌─────────┐        ┌─────────┐        ┌─────────┐
  │ Block 0 │───────>│ Block 1 │───────>│Block 12345│─────>│Block 12346│
  │ 创世区块 │        │         │        │ (当前块) │       │         │
  └─────────┘        └─────────┘        └─────────┘        └─────────┘
       │                  │                   │                  │
  PrevHash=0000      PrevHash=Hash0      PrevHash=Hash1    PrevHash=Hash12345


═══════════════════════════════════════════════════════════════════════════════════════════════

说明：
1. 每个区块包含：区块头、区块数据(交易列表)、区块元数据
2. TxID = SHA256(Nonce + Creator)，不包含交易内容
3. 数据以JSON格式存储在区块链中
4. 区块通过前区块哈希连接形成链
5. 每笔交易都有背书签名，确保数据可信
