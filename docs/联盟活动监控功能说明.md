# 联盟活动监控功能说明

## 功能概述

联盟活动监控是管理员端的一个重要功能模块，用于实时监控联盟中所有组织的业务活动，包括病历创建、补充记录、授权请求、药品订单和保险报销等。

## 功能特点

### 1. 实时活动监控
- 显示联盟中所有组织的最新业务活动
- 按时间倒序排列，最新活动在最前面
- 支持查看活动详情，包括操作人、患者、组织、科室等信息

### 2. 多维度筛选
- **组织筛选**：可以按组织（协和医院、301医院、温江社区医疗中心、监管中心）筛选活动
- **活动类型筛选**：支持按活动类型（创建病历、补充记录、授权请求、药品订单、保险报销）筛选
- **日期范围筛选**：可以选择特定日期范围查看历史活动

### 3. 统计数据展示
在页面顶部显示四个统计卡片：
- **病历总数**：系统中所有病历记录的数量
- **补充记录**：所有补充诊疗记录的数量
- **药品订单**：所有药品订单的数量
- **保险报销**：所有保险报销申请的数量

### 4. 活动时间线
- 以时间线形式展示活动记录
- 不同类型的活动使用不同的颜色标识
- 每条活动记录包含：
  - 活动类型标签
  - 组织名称标签
  - 活动描述
  - 相关人员信息（医生、患者）
  - 科室信息
  - 创建时间
  - 查看详情按钮

### 5. 分页功能
- 支持自定义每页显示数量（10、20、50、100条）
- 支持页码跳转
- 显示总记录数

## 监控的活动类型

### 1. 创建病历 (prescription)
- 描述：医生为患者创建病历
- 信息：医生姓名、患者姓名、组织名称、科室
- 颜色：蓝色

### 2. 补充记录 (supplement)
- 描述：医生添加补充诊疗记录（复诊/随访/急诊）
- 信息：医生姓名、组织名称、科室、记录类型
- 颜色：绿色

### 3. 授权请求 (access_request)
- 描述：医生请求访问患者的病历
- 信息：医生姓名、患者姓名、组织名称
- 颜色：橙色

### 4. 药品订单 (drug_order)
- 描述：患者在药店下单购买药品
- 信息：患者姓名、药店名称、药品名称
- 颜色：红色

### 5. 保险报销 (insurance_claim)
- 描述：患者向保险机构申请报销
- 信息：患者姓名、保险机构名称
- 颜色：灰色

## 访问路径

### 方式一：通过侧边栏导航
1. 登录管理员账户
2. 点击左侧菜单"监管中心"
3. 点击"活动监控"

### 方式二：通过首页快捷入口
1. 登录管理员账户
2. 在首页"快捷功能"区域
3. 点击"活动监控"卡片

## 使用场景

### 1. 日常监管
管理员可以通过活动监控功能，实时了解联盟中各个组织的业务活动情况，确保系统正常运行。

### 2. 异常排查
当发现某个组织的活动异常（如活动数量突然增加或减少），可以快速定位问题。

### 3. 数据审计
通过筛选特定日期范围和组织，可以进行数据审计，查看历史活动记录。

### 4. 业务分析
通过统计数据和活动记录，可以分析各个组织的业务量和活跃度。

## 技术实现

### 前端
- 页面路径：`/account/activity-monitor`
- 组件文件：`fabric-mims-main/application/web/src/views/account/activity-monitor/index.vue`
- API文件：`fabric-mims-main/application/web/src/api/activity.js`

### 后端
- API文件：`fabric-mims-main/application/server/api/v2/activity.go`
- Service文件：`fabric-mims-main/application/server/service/activity.go`
- 路由配置：`fabric-mims-main/application/server/routers/router.go`

### API接口

#### 1. 获取联盟活动列表
- 接口：`POST /api/v2/getAllianceActivities`
- 参数：
  - `page`: 页码
  - `pageSize`: 每页数量
  - `organization`: 组织MSPID（可选）
  - `activityType`: 活动类型（可选）
  - `startDate`: 开始日期（可选）
  - `endDate`: 结束日期（可选）
- 返回：活动列表和总数

#### 2. 获取活动统计数据
- 接口：`POST /api/v2/getActivityStatistics`
- 参数：无
- 返回：各类活动的统计数据

## 数据来源

活动数据来自以下数据库表：
- `prescriptions`：病历表
- `supplement_records`：补充记录表
- `access_requests`：授权请求表
- `drug_orders`：药品订单表
- `insurance_claims`：保险报销表

## 注意事项

1. 此功能仅对管理员角色开放
2. 活动数据实时从数据库查询，确保数据准确性
3. 大量数据查询时建议使用筛选条件，提高查询效率
4. 点击"查看详情"会跳转到相应的详情页面
