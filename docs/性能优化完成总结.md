## 使用说明

### 前端缓存

缓存会自动管理，无需手动操作。如需手动清除：

```javascript
import { clearAccountCache } from '@/utils/accountCache'

// 清除缓存
clearAccountCache()
```

### 后端缓存

缓存会自动管理。在以下情况会自动清除：
- 注册新用户
- 缓存过期（5分钟后）

如需手动清除：

```go
import "application/pkg/cache"

// 清除账户列表缓存
memCache := cache.GetGlobalCache()
memCache.Delete("account_list")

// 清除所有缓存
memCache.Clear()
```

## 注意事项

### 1. 缓存一致性

当数据发生变化时，需要清除相关缓存：

- ✅ 注册用户：已自动清除账户列表缓存
- ⚠️ 更新用户：需要添加清除缓存逻辑
- ⚠️ 删除用户：需要添加清除缓存逻辑

### 2. 缓存有效期

- 前端缓存：5分钟
- 后端缓存：5分钟
- 可根据实际情况调整

### 3. 内存占用

- 账户列表缓存：约 50KB
- 总体影响：可忽略
- 定期自动清理过期缓存

### 4. 错误处理

- 缓存失败不影响主要功能
- 自动降级到直接查询
- 错误信息记录在控制台

## 后续优化建议

### 1. Redis缓存（推荐）

如果系统需要支持分布式部署，建议使用Redis：

```go
// 安装Redis
// 修改代码使用Redis替代内存缓存
import "github.com/go-redis/redis/v8"
```

优点：
- 支持分布式
- 缓存持久化
- 更大的缓存容量

### 2. 数据预加载

在用户登录后预加载常用数据：

```javascript
// 登录成功后
this.$store.dispatch('account/loginWithPassword', userInfo)
  .then(() => {
    // 预加载账户列表
    getAccountMap()
    
    // 预加载健康档案（如果是患者）
    if (role === '病人') {
      getHealthProfile('all')
    }
  })
```

### 3. 更多缓存

可以为以下数据添加缓存：
- 病历列表
- 药品订单列表
- 组织列表
- 统计数据

### 4. 性能监控

添加性能监控，持续优化：

```javascript
// 记录加载时间
const startTime = performance.now()
// ... 加载数据
const endTime = performance.now()
console.log(`加载耗时: ${endTime - startTime}ms`)
```
