## 功能概述

隐私溯源功能用于记录和追踪谁访问了患者的病历，保护患者隐私安全。所有访问记录都会存储在区块链上，确保不可篡改。

## 功能特点

1. **自动记录**：当医生或其他角色查看患者病历时，系统自动记录访问日志
2. **区块链存储**：访问记录存储在区块链上，确保数据不可篡改
3. **MySQL缓存**：同时在MySQL中存储一份，方便快速查询
4. **患者可见**：患者可以查看自己病历的所有访问记录
5. **统计分析**：提供访问统计，包括总访问次数、不同访问者数量等

## API接口

### 1. 记录病历访问

**接口**：`POST /api/v2/recordPrescriptionAccess`

**参数**：
```json
{
  "prescription_id": "病历ID",
  "prescription_no": "病历编号",
  "patient_id": "患者ID",
  "patient_name": "患者姓名",
  "accessor_id": "访问者ID",
  "accessor_name": "访问者姓名",
  "accessor_role": "访问者角色",
  "accessor_organization": "访问者组织MSPID",
  "accessor_organization_name": "访问者组织名称",
  "access_type": "访问类型",
  "access_reason": "访问原因"
}
```

**返回**：
```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "log_id": "日志ID",
    "message": "访问日志已记录"
  }
}
```

### 2. 获取我的访问日志

**接口**：`POST /api/v2/getMyAccessLogs`

**参数**：
```json
{
  "patient_id": "患者ID",
  "page": 1,
  "page_size": 20
}
```

**返回**：
```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "logs": [...],
    "total": 100,
    "page": 1,
    "page_size": 20
  }
}
```

### 3. 获取访问统计

**接口**：`GET /api/v2/getAccessStatistics?patient_id=xxx`

**返回**：
```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "total_access": 100,
    "unique_accessors": 10,
    "recent_access": 5
  }
}
```

## 前端集成

### 1. 在病历详情页记录访问

在`prescription/detail/index.vue`的`loadMedicalHistory`方法中，加载病历成功后调用记录接口：

```javascript
import { recordPrescriptionAccess } from '@/api/accessTrace'

// 在loadMedicalHistory方法中，成功加载病历后
if (response && response.code === 200) {
  this.medicalHistory = response.data
  
  // 记录访问日志（如果不是患者本人）
  if (this.currentUser.account_id !== this.medicalHistory.patient_id) {
    recordPrescriptionAccess({
      prescription_id: this.prescriptionId,
      prescription_no: this.medicalHistory.prescription_no,
      patient_id: this.medicalHistory.patient_id,
      patient_name: this.medicalHistory.patient_name,
      accessor_id: this.currentUser.account_id,
      accessor_name: this.currentUser.account_name,
      accessor_role: this.currentUser.role,
      accessor_organization: this.currentUser.organization || '',
      accessor_organization_name: this.currentUser.organization_name || '',
      access_type: 'view',
      access_reason: '查看病历详情'
    }).catch(err => {
      console.error('记录访问日志失败:', err)
      // 不影响主流程
    })
  }
}
```

## 隐私保护规则

1. **患者本人访问不记录**：患者查看自己的病历不会产生访问记录
2. **医生访问需授权**：医生需要获得患者授权才能查看病历
3. **访问记录不可删除**：所有访问记录存储在区块链上，不可删除或修改
4. **实时通知**：（未来功能）当有人访问病历时，可以实时通知患者

## 安全建议

1. 定期检查访问记录，发现异常及时报告
2. 不要将账户密码告诉他人
3. 如发现未授权访问，立即联系管理员
4. 定期更改密码，保护账户安全
